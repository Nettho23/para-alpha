# Para Alpha

Felicitación digital de cumpleaños de parte de Jaf, con jardín interactivo, safari, jirafa animada, carta, fotografías y Las Mañanitas.

## Abrir la página

El sitio está hecho con HTML, CSS y JavaScript y no necesita instalar dependencias. Abre `index.html` o sirve esta carpeta como un sitio estático.

## GitHub Pages

El archivo `index.html` está en la raíz. Para publicar, selecciona la rama principal y la carpeta `/ (root)` en Settings → Pages, si está disponible para el repositorio.

## Música

El audio se activa con «Escuchar Las Mañanitas» y puede pausarse desde el botón flotante. Los créditos y la licencia están en `assets/audio/CREDITS.txt` y al pie de la página.
